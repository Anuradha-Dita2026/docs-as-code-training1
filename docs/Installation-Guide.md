# GitHub
Create an account and repository
1.  Go to github.com/join. Choose a professional username — this will appear in your portfolio URL, e.g. github.com/username, so avoid nicknames. Verify the account by email.
2.  Once logged in, click the + icon top-right → New repository.
3.  Repository name: type username.github.io — replacing username with your exact GitHub username. This exact naming pattern is what activates a free personal site.
4.  Set visibility to Public (GitHub Pages on the free tier requires a public repo for personal sites).
5.  Check “Add a README file”, then click Create repository.


## Module 1: Preparation
From Git (Your Local) to GitHub
Step 1: Open folder in VSC - Local folder (Git)
1. Open VSC
2. On the left sidebar, click Open Folder.
3. Navigate to your folder, select and open in VSC.
Example view:
My-Documentation-Project
├── index.html
├── README.md
├── docs/
└── images/
 
### Step 2: Create a GitHub Repo
1. On the left sidebar, click Source Control icon.
2. Under Changes add a line (initial Commit) and select ✓ Commit and approve the message on right-side VSC bottom.
3. Click Publish Branch.
Notes:
- Authorization: You may be asked o authorize using GitHub account credentials if you are not already signed in.
- Private/Public Repo: If the message appears, select Public option as you need to use GitHub Pages.
4. Verify the new repo in GitHub.
