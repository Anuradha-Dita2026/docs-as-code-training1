From GitHub to Git (Your local)
Step 1: Create a repo or fork an existing repo
Create a Repo
1.      In your GitHub account, select +>New Repository.
2.      Add files and create a repo.
3.      In the repo, add the required index.htm and css files.
Fork an existing repo
1.      Open the repo that you want to fork (Copy)
2.      Click the fork icon.
3.      Follow instructions on Create a new fork screen and Create fork.
Step 3: Clone the repo using VSC
1.      Open the GitHub repo that you want to clone.
2.      Click Code.
3.      Copy HTML code.
4.      Open VSC and verify if you are signed in.
5.      Open Command Pallete on the top search box.
6.      Type git clone and paste the github repo url.
